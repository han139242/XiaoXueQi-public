# 前端核心文件答辩说明

## 一条主线

```text
package.json 提供启动命令和依赖
→ npm run dev 启动 Vite
→ Vite 读取 vite.config.js
→ 浏览器加载 index.html
→ index.html 加载 main.js
→ main.js 创建 Vue 应用并挂载到 #app
→ App.vue 中的 RouterView 显示当前路由页面
→ router 在跳转前检查登录状态和页面权限
```

## package.json

`package.json` 是项目清单，使用严格 JSON 格式，因此不能加入 `//` 或 `/* */` 注释。

### 基本信息

- `name`：项目包名，本项目为 `badminton-mes-pc`。
- `private: true`：禁止误操作发布到 npm 公共仓库。
- `version`：当前项目版本。
- `type: module`：项目使用 ES Module，可以使用 `import` 和 `export`。

### scripts

- `npm run dev`：执行 `vite`，启动开发服务器和热更新。
- `npm run build`：执行 `vite build`，把源码打包到 `dist`。
- `npm run preview`：在本地预览 `dist` 的生产构建效果。

### dependencies

- `vue`：Vue 3 核心框架。
- `vue-router`：前端路由。
- `axios`：请求 Spring Boot API。
- `element-plus`：后台管理界面组件库。
- `echarts`：首页图表和生产大屏。
- `dayjs`：日期时间处理。
- `js-cookie`：Cookie 读写。

### devDependencies

- `vite`：开发服务器和打包工具。
- `@vitejs/plugin-vue`：让 Vite 编译 `.vue` 文件。
- `sass-embedded`：编译 Sass/SCSS 样式。

答辩回答：`dependencies` 是应用运行功能依赖，`devDependencies` 主要用于开发、编译和打包。

## package-lock.json

`package-lock.json` 由 npm 自动生成，不能手动添加注释。它记录本次实际安装的所有直接、间接依赖精确版本、下载地址和完整性校验值。

```text
package.json：声明“允许安装什么版本”
package-lock.json：锁定“这次实际安装了什么版本”
node_modules：依赖安装后的真实文件
```

它应提交到 Git；`node_modules` 不应提交，因为可以通过 `npm ci` 按锁文件重新安装。

## 五个高频问题

1. `main.js` 做什么？

   创建 Vue 应用，注册 router 和 Element Plus，再挂载到 `#app`。

2. `App.vue` 为什么只有 RouterView？

   它是根组件，实际页面由 router 根据 URL 动态放进 RouterView。

3. router 做什么？

   建立 URL 与页面组件的对应关系，并通过路由守卫校验登录状态和页面权限。

4. Vite 代理做什么？

   开发时把前端的 `/api` 请求从 5173 转发到后端 8088，统一请求路径并处理跨域。

5. `#app` 是什么？

   `#` 表示按 id 查找，`#app` 指向 index.html 中的 `<div id="app"></div>`，它是 Vue 接管网页的挂载位置。
